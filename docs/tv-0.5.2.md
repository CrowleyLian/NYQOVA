# 0.5.2：遥控焦点与歌单专辑视图

## 操作入口

- 删除右上角项目操作和页面操作。长按项目或在项目上按遥控器菜单键打开对应菜单；没有项目焦点时不再弹出页面菜单。
- 搜索弹窗在已有搜索词时提供清除搜索。扫描仍在设置中。

## 焦点

- 歌手/风格切换不再重建分类列表，仅更新选中状态；右键进入内容，左键返回当前分类。
- 长按菜单关闭后恢复对应项目。收藏只更新相关卡片；收藏页移除项目后恢复相邻项，空列表聚焦搜索。
- 翻页、排序和歌单移除仍通过项目标识/相邻位置和滚动锚点恢复焦点。
- 内容最后一行按下进入底部播放/暂停；分页边界继续读取下一页并保留在内容区，不提前进入播放栏。
- 导航最底部的收起/展开按钮按下或按右进入播放栏；导航其他项目按右进入当前内容。
- 播放栏左右按上一曲、播放/暂停、下一曲、歌曲信息、收藏、队列移动。信息确认进入播放页，上键返回进入播放栏前的位置。无队列时隐藏播放栏。

## 歌单视图

- 自建歌单、NAS 文件夹歌单，以及全部音乐/收藏/最近等内置歌曲范围可在视图菜单选择歌曲或专辑，并按来源/歌单分别记忆。
- 专辑数量与曲目数量使用同一个数据库范围；专辑卡片只统计当前歌单所含曲目。
- 歌单内进入专辑后保留歌单/文件夹限制，播放全部及添加到其他歌单也使用该范围。CUE 仍显示已入库的逻辑曲目。
- 专辑聚合按 80 项分页，支持现有封面网格/列表和专辑/歌手排序；切换视图不更改当前播放队列。

## 验证

版本 0.5.2（11），minSdk 23、Media3 1.4.1 与 armeabi-v7a 不变。

```powershell
./scripts/build.ps1 -UseMirror -IncludeDeviceTests -TestRunner com.nyqova.app.TvInstrumentation
./scripts/test-tv-ui.ps1 -Phases remote,search,counts,menus
```

remote 专项使用临时手动/文件夹歌单和现有 NAS 曲目，检查收藏、取消收藏、歌手/风格左右移动、分页边界、歌单专辑子集、记忆视图、播放队列子集、播放栏进出与空队列隐藏；完成后清理临时歌单并恢复收藏、队列和设置。

USB 手机按 32 位进程和 1920×1080 测试。测试脚本保留测试前显示设置，本次手机继续保持用户指定的 1080P / density 320。Android 9 目标电视盒子仍需本机验收。

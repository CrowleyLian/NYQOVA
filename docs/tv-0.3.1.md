# 0.3.1：Lucide、导航收起与播放页自动进入

## 图标

导航、播放/暂停、上一首/下一首、循环模式、收藏、搜索、首页卡片、封面占位、队列及全屏歌词控制统一采用 Lucide。移除了使用 Unicode 字形绘制图标的代码。

资源直接随 APK 打包为 Android 原生 VectorDrawable，不通过网络加载图标，不依赖设备安装的字体，不引入原生解码库。矢量资源统一 24×24 视口和 2 单位线宽，图标按钮居中，保留遥控器焦点边框和文字朗读名称。

官方资源、固定版本、哈希与完整许可见 `third-party/lucide/`；许可也包含在 APK 的 `assets/licenses/lucide.txt`。填充收藏心形和主题色圆点从官方矢量路径派生。

## 导航

侧栏下方有“收起导航”按钮。收起后保留全部分类图标，内容区域同时变宽；同一位置变为“展开导航”。状态保存在设备，关闭 App 或覆盖升级后继续保留。收起后仍可使用方向键选择分类，并保持原来的音乐库、歌单与当前播放。

“设置 → 外观设置 → 收起导航栏”提供同一开关。较矮屏幕的导航仍可滚动，设置与展开按钮不会因屏幕高度不足而失去入口。

## 自动进入播放页

入口：“设置 → 播放与歌词 → 自动进入播放页”。默认 **无操作 30 秒**；可选关闭、15/30/60/120/300 秒，或自定义 5–3600 秒。设置即时生效并保存。

| 当前状态 | 行为 |
| --- | --- |
| 正在播放且 App 在前台 | 达到无操作时间后切换到播放页 |
| 遥控器、触摸或滚动操作 | 从最后一次操作重新计时 |
| 暂停、停止、没有曲目或缓冲中 | 不自动跳转；恢复实际播放后重新计时 |
| 输入框或其他弹窗打开 | 不打断弹窗；关闭后重新计时 |
| App 后台或全屏歌词页 | 不从后台强行导航 |
| 已经处于播放页 | 不重复切换，也不重新加载歌曲 |

自动进入只改变页面，不启动原本暂停的音乐、不重建队列、不改变曲目进度。“进入 App 自动继续上次播放”仍是独立设置。

## 验证与交付

运行 `scripts/build.ps1 -UseMirror -IncludeDeviceTests -TestRunner com.nyqova.app.TvInstrumentation`：核心单元测试、Lint、APK 和 v7a ABI 检查。

运行 `scripts/test-tv-ui.ps1`：保存手机显示参数，临时切换 1080P 验证尺寸，安装后依次运行音乐库回归、进程冷启动续播和本版交互检查，最后恢复手机原显示设置。测试不在源码或 APK 中保存 NAS 密码。

本版新增检查覆盖：所有使用中的 Lucide 矢量原生加载、APK 许可、遥控器收起/展开与持久化、图标导航、暂停不跳转、操作重置计时、关闭功能、输入弹窗保护、后台保护及**真实等待 30 秒**的播放页进入。原音乐库、收藏、歌单、CUE 和冷启动续播也进行回归。

设备为 USB 连接的 Honor COL_AL10（Android 10/API 29），强制 32 位 ARM 运行；1080P 为手机临时显示尺寸验证，受手机安全区影响。目标 Android 9 TV 盒子尚未连接，不能视为已完成盒子实测。minSdk 23、armeabi-v7a 兼容约束保持不变。

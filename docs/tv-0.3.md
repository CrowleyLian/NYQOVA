# 0.3.0 参考布局版

本阶段依据设计参考图实现。参考图仅在本地 `参考布局/` 留存，不随公开源码分发。分类侧栏替代此前的三个导航按钮；底部播放条进入独立播放页，设置有单独入口。

## 界面与使用

- 首页：随机漫游、收藏、最近播放、最近添加四张卡片，以及最近播放和最近入库专辑。漫游将全库打乱后生成独立队列。
- 左侧：收藏、最近、专辑、歌手、风格、音乐库、歌单、NAS 文件夹和设置。
- 专辑：1080P 下五列封面，网格/列表可切换。进入后直接展示曲目，CUE 使用逻辑分轨；原始整轨默认隐藏。
- 歌曲：曲名、歌手、专辑、播放标记、收藏标记、时长、文件大小和格式。CUE 文件大小标为“整轨”，避免误认为每首歌曲都占用同样容量。
- 歌手/风格：左侧分类列表，右侧歌曲；歌手可切换歌曲/专辑。风格从媒体标签和 CUE `REM GENRE` 读取；缺失时归入未分类，不自动猜测风格。
- 播放页：左侧封面、曲目信息、进度和控制，右侧五行同步歌词。背景从封面取色。可切换仅封面、封面加歌词和全屏歌词；歌词文字默认转为简体，歌名保持原始标签。
- 进度焦点：左右按设置步长跳转，确认键输入“分:秒”。CUE 使用当前曲目的相对时间。
- 队列抽屉：确认曲目切换播放；底部“曲目操作”提供移除、上下移动和下一首播放。所有功能可用方向键/确认/返回操作，长按只是快捷方式。
- 设置：外观、音乐库、播放与歌词、服务器四组；连接与发现、扫描/取消、隐藏整轨、记忆与自动续播、在线匹配、简体、跳转步长、歌词字号、主题色、动画及缓存清理。

## 收藏与歌单

歌曲收藏形成“我喜欢”。专辑收藏独立保存，通过“视图 → 只看收藏专辑”查看，不会自动收藏整张专辑的每一首。

歌单支持手动建立、添加歌曲/整张专辑、去重、重命名、移除、上下调整顺序和删除。文件夹歌单通过 NAS 目录选择器指定路径，可选择是否包含子目录；内容随音乐库扫描更新。删除歌单和移出歌曲只修改设备内数据库，不修改 NAS。

点击歌曲时，当前专辑、歌单、收藏、搜索或排序结果形成队列快照。收藏或歌单后续变化不会改动正在播放的队列；下一首播放和加入队列需要明确操作。

## 保存与升级

数据库按 v1 → v2 → v3 逐步迁移，保留旧扫描结果；收藏、歌单和历史与扫描快照分开保存。标签读取器升级后，下一次扫描补充风格和大小并保留稳定歌曲 ID。

连接继续使用原 Android Keystore 保存格式。队列及进度采用应用私有目录的原子文件，不保存 NAS 密码。队列只在修改时写入，进度定期保存；静止进度去重。恢复包含曲目索引、CUE 裁剪边界、相对位置、循环和随机模式。默认启动自动继续，可关闭；网络不可用时保留记忆，恢复网络后可重新播放。

## 验证

构建和静态检查：`scripts/build.ps1 -UseMirror -IncludeDeviceTests -TestRunner com.nyqova.app.TvInstrumentation`，包括核心单元测试、APK、设备测试 APK、Lint 和原生 ABI 检查。

已用 USB 连接的 Honor COL_AL10（Android 10/API 29）强制 32 位 ARM 运行。临时设为 1920×1080 显示尺寸，使用方向键事件验证；手机的系统安全区使应用逻辑画布小于 TV 标准画布。测试后恢复手机原显示设置。目标 E900V20D Android 9 电视盒子尚未连接，本次不将手机测试等同于盒子实测。

- 覆盖安装保留加密连接、30 张专辑和 101 首 NAS 音乐。
- 205 首隔离测试数据验证分页完整性、搜索转义、分类过滤和目录边界。
- 验证专辑/歌曲收藏独立、歌单去重和排序、移除不影响音乐文件、扫描替换保留收藏及歌单、历史倒序。
- 验证 1080P 五列专辑、遥控器进入曲目、返回恢复焦点、CUE 原始文件隐藏。
- 验证真实 NAS 播放、在线/缓存中文歌词、左右进度跳转、队列抽屉与设置界面。
- 外部强制结束进程后，验证队列、CUE 曲目与相对进度、循环模式和自动播放恢复。

完整报告在 `artifacts/tv-validation-main.txt`、`artifacts/tv-validation-resume.txt`；截图文件为 `artifacts/tv-*-1080.png`。APK 为 `artifacts/NYQOVA-0.3.0-v7a-debug.apk`。APK 和截图作为本地交付物，不写入 Git。

兼容范围保持 minSdk 23、armeabi-v7a；APK 目前不含任何 `.so`，不存在仅 arm64 的解码依赖。compileSdk/targetSdk 34 不代表要求 Android 14。新解码器仍需单独验证 v7a，当前没有加入 APE/DSD 解码器。

# 0.5.3：歌单去重、主题色、导航提示与遥控搜索

- 歌单概览仅显示新建歌单和已保存的手动/文件夹歌单；移除全部音乐、我喜欢、最近播放和最近入库四个重复入口。数量不再包含内置入口。
- 主题色同时应用于焦点边框、选中/按下背景、图标、播放进度和系统弹窗控件。选中背景改为主题色与深色面板混合，不再固定红色；Activity 创建前选择对应 Android 主题，歌词页也初始化同一主题。当前色块显示已选，切换后保留设置页和色块焦点。
- 导航收起时，在焦点图标右侧浮现菜单名称；离开导航、进入其他页面、失去窗口焦点或展开导航时隐藏。提示不接收焦点、不增加遥控步骤，收起宽度不变。
- 点击搜索先选择首字母搜索/文字搜索；首字母面板提供 A–Z、0–9 和 #，按当前页面范围搜索。歌曲范围匹配歌名/歌手/专辑，专辑范围匹配专辑/歌手，歌手/风格筛选对应分类。歌单按名称、NAS 文件夹按当前内容筛选。支持清除和返回恢复。
- 中文简繁体名称按拼音首字母分组；Android 7 起使用系统 ICU 不可变字母索引，Android 6 对常见 GB2312 汉字使用兼容分组。数字归 0–9，无法分类的符号/文字归 #。多音字遵循对应分组规则，不承诺人工读音消歧。
- Room v4→v5 只增加 search_initials 名称索引表和索引，保留歌曲、收藏、歌单及音频任务。第一次首字母搜索在后台按 256 个新名称分批补建索引；标签变化后仅补建缺失名称，不读 NAS 音频，不要求重新扫描。

版本 0.5.3（12），仍为 Android 6.0 起、armeabi-v7a、Media3 1.4.1。

# 0.6.0：四套外观主题

入口：设置 → 外观设置 → 外观主题。选择主题立即应用并保留设置页、滚动位置和焦点；播放由原服务继续，切换不重建队列或跳回起点。

| 主题 | 背景与文字 | 默认强调色 |
| --- | --- | --- |
| 经典深色 | 灰紫、柔和浅色文字 | 珊瑚红 #E6435A |
| 午夜蓝 | 深海军蓝、冷白文字 | 冰蓝 #72B7FF |
| 暖调唱片 | 暖炭灰、米白文字 | 琥珀金 #E5AB55 |
| 清晰高对比 | 纯黑、明亮白字和灰色边界 | 青色 #40E0D0 |

强调色单独提供八种选择，保留此前五种，并增加冰蓝、琥珀金、青色。每套主题分别记住强调色，切回时恢复自己的选择。升级保留用户原有强调色，未选择主题时使用经典深色。

## 统一范围

- 根背景渐变、导航、分类/设置面板、播放栏、占位封面、首页卡片统一使用调色板。
- 主文字、次文字、图标、歌词和系统控件采用对应明暗与色温。
- 原生主题资源覆盖四套调色板和八种强调色组合，并使用编译期资源 ID 引用。
- 弹窗使用统一构造入口；窗口背景、列表选择器和原生动作按钮使用同一套主题。搜索键盘、歌词弹窗、许可页和播放队列一并跟随。
- 播放页保持封面本色，封面氛围背景与主题底色混合；高对比主题进一步压低氛围颜色，避免影响文字清晰度。
- 焦点始终同时具备边框和背景变化。高对比主题将焦点边框从 2dp 增为 3dp，并为非透明面板增加灰色边界。

USB Android 10 手机以明确的 32 位和 1920×1080 验证：

- 播放真实 NAS 曲目并定位至 20 秒后，依次点击四套主题；逐次验证媒体 ID、队列、播放状态、循环模式与进度保留。
- 核对原生弹窗背景/文字属性、主题标识及设置焦点恢复；采集四套首页和设置截图，暖调/高对比搜索键盘、高对比播放页与队列截图并人工检查布局。

- 原有主题色控件、收起导航提示、统一搜索、ZJL/GD 首字母、当前歌曲继续、收藏焦点、分页、歌单专辑、播放栏和菜单回归通过。

手机保持用户要求的 1080P / density 320。Android 9 目标电视盒子尚未连接，本机性能与颜色表现仍需在该盒子上体验。

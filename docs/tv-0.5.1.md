# 0.5.1：按页面搜索与关于

- 修复搜索提交时强制切换到全部歌曲的问题。专辑墙保持专辑结果和当前收藏筛选；专辑详情、收藏、最近播放、歌曲歌单和文件夹歌单保留原范围。
- 歌手/风格搜索筛选左侧分组，右侧保留选中分组的歌曲/专辑。分组搜索词独立保存，不会继续过滤右侧歌曲标题；空结果清空旧曲目和信息区。
- 歌单页按名称/说明搜索播放入口，数量排除新建按钮；NAS 文件夹页筛选当前文件夹内容。首页搜索进入全库歌曲搜索。
- 搜索按钮随页面说明搜索范围。输入空文本或页面操作中的清除搜索可恢复完整范围；从搜索到的专辑返回时恢复搜索结果和焦点。
- 桌面和 TV 启动器名称统一为“聆序”。设置新增“关于”：聆序、NYQOVA、NAS 音乐播放器、作者 L.VSN、从实际安装包读取的版本名/版本号和平台说明。
- 开源许可统一移动到关于页。版本 0.5.1（10），Android 6.0 起及 v7a 配置不变。

验证命令：

```powershell
./scripts/build.ps1 -UseMirror -IncludeDeviceTests -TestRunner com.nyqova.app.TvInstrumentation
./scripts/test-tv-ui.ps1 -Phases search,counts,menus
```

搜索专项通过真实搜索按钮和输入弹窗验证专辑结果类型、专辑内搜索、返回保留条件、空结果/清除、歌手分组搜索、歌单筛选及计数，同时核对桌面名称和关于信息。USB 手机按 32 位和 1920×1080 测试；Android 9 盒子本机验收仍需在目标设备完成。

# 0.3.2：D1–D6 与 T1–T5

本检查点按已确认的清单调整菜单、作用范围、返回焦点和队列保护，最终随 [0.4.0](tv-0.4.0.md) 交付。之后追加确认的扫描优化一并实现；T6、T8–T9 的专用排序模式、歌词手动跟随等不包含在本轮。

## 菜单收口

| 清单 | 实现 |
| --- | --- |
| D1 | 播放页“更多”仅保留添加到歌单、封面/歌词显示切换；收藏与全屏歌词使用外部图标 |
| D2 | 删除歌曲菜单的“播放此曲”和列表菜单的“播放此列表”；确认曲目播放，具体歌曲列表使用“播放全部” |
| D3 | 队列菜单删除“播放”，确认队列行即可播放 |
| D4 | 歌手只使用页面上的歌曲/专辑切换，视图菜单不再重复；风格不显示无效专辑按钮 |
| D5 | 新建歌单使用歌单页首项；收起/展开导航使用侧栏按钮；删除对应重复菜单和设置开关 |
| D6 | 定位时间统一为进度条确认键；进度条聚焦时显示方向键步长和确认定位提示 |

## TV 交互

- **T1**：顶部页面菜单只处理刷新、清除搜索。项目操作按钮显示目标名称，选中行保持标记；遥控器菜单键和长按都能打开当前聚焦项目的菜单。没有选中可操作项目时，不默认操作第一首歌曲。
- **T2**：专辑网格/列表切换留在当前专辑范围，专辑按名称或歌手排序；歌曲范围按歌名、歌手或专辑排序。手动歌单、CUE 专辑、最近播放等固定顺序不再显示无效排序。歌手切换标明选中状态。
- **T3**：“播放全部”仅出现在具体歌曲列表；首页、专辑墙、筛选后的专辑墙、歌单总览不提供范围不明的全库播放。列表播放使用当前搜索、分类或歌单快照。
- **T4**：曲目使用稳定 ID 保存焦点，修改后恢复原歌曲或相邻歌曲，并保留滚动位置。播放器返回原始歌曲/按钮；从设置自动进入播放器后可返回设置。设置项使用稳定标签保存焦点，数值更新及外观重建后恢复位置。
- **T5**：清空队列先确认，默认焦点为取消；取消不影响播放。再次确认正在播放的队列行不回到开头，暂停时从当前位置继续。

## 验证与交付

构建：`scripts/build.ps1 -UseMirror -IncludeDeviceTests -TestRunner com.nyqova.app.TvInstrumentation`。

设备验证：`scripts/test-tv-ui.ps1`，包含音乐库回归、进程冷启动恢复、播放状态下的 30 秒自动进入，以及本版菜单与焦点流程。可用 `-Phases @('menus')` 单独运行菜单检查；`-Phases @('scan')` 按当前 NAS 目录重新扫描索引。脚本会恢复设备原显示设置，不修改 NAS 文件。

新增用例包括遥控器菜单目标、页面菜单去重、同范围切换及实际排序、隐藏范围不明确的播放按钮、歌单移位/删除后的邻近焦点、播放返回原行、进度条确认输入、当前队列行保持进度、清空取消与确认，以及设置更新后焦点恢复。

最终报告为 `artifacts/tv-0.4.0-*.txt`，APK 为 `artifacts/NYQOVA-0.4.0-v7a-debug.apk`。兼容约束仍为 minSdk 23、armeabi-v7a，无新增原生库。设备验证使用 Android 10 手机的 32 位运行与 1080P 显示尺寸；Android 9 目标盒子仍需实测。

# 0.4.1：全屏、队列与在线来源

- 队列底部删除“曲目操作”，长按歌曲仍可移出、上移、下移、下一首播放；清空入口与默认取消确认保留。
- 播放页隐藏侧栏、迷你播放器，并取消音乐库外层边距；开启沉浸布局，画面覆盖完整 1920×1080。原来的全屏歌词图标仍用于只显示歌词的独立页面。
- 设置新增“在线服务”，统一在线歌词/封面开关、来源选择与当前歌曲歌词重试。歌词自动模式为 LRCLIB → LrcAPI，封面为 MusicBrainz/CAA → LrcAPI；也可指定单一来源。本地与缓存优先。
- 主源抛出网络错误或未匹配时继续备用源，不再因主源一次失败直接结束。当前歌词失败后在前台自动再试一次；切歌、关闭在线歌词或取消请求会阻止旧结果更新。
- LrcAPI JSON 歌词按曲名、歌手、录音版本和时长校验，再选择同步歌词；未经匹配的结果保留为手动候选。来源名随缓存保存，不把备用结果标成 LRCLIB。封面备用匹配校验专辑及歌手，仅接收受支持的 HTTPS 图片来源；不发送 NAS 密码、路径或音频。
- 有艺术家标签的数字开头歌名（如《18 And Life》《21 Guns》）保留真实数字，避免误判成文件序号。
- 扫描结束/失败提示提供关闭按钮；未聚焦时八秒后自动收起，避免常驻音乐库。设置 → 音乐库管理 → 查看未补全文件 / 重试，保留待办数量、失败文件与后续读取错误类别，不清空曲库。

备用服务使用 [HisAtri/LrcAPI 的公开接口与文档](https://github.com/HisAtri/LrcApi)，包括 `/jsonapi`、`/cover`。只调用接口，没有复制或打包该项目实现。公共服务仍可能超时或缺少特定录音；设置允许手动选择来源及重试。

验证：15 项核心测试、Android Lint、v7a 包检查，以及 USB 手机以 32 位进程和 1080P 显示完成全屏边界、队列长按、提示自动消失、在线设置、真实备用歌词/封面与缓存、菜单/播放回归。未补全的两份文件可在设备设置查看；不将补全失败直接判定为音频损坏。
